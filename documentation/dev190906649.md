# Metal Compiler Request ID Engineering Type

An identifier that represents a compilation request for a shader
(vertex, fragment, compute).

:::: {#dev190906649us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `metal-compiler-request`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
