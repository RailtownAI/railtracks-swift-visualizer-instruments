# Text Addresses Engineering Type

An array of text addresses.

:::: {#dev85000363us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `text-addresses`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

:::: {#dev85000363dc .Subhead}
## Display Conventions {#display-conventions .Name}

Debugging display only. Fragments lack the process they came from, so
those text addresses can\'t be converted to symbols or further analyzed.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev85000363ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

The encoding is an array of text addresses. These addresses are most
often the call sites of a backtrace, but these fragments can\'t be
properly analyzed until they\'re turned into a backtrace.
