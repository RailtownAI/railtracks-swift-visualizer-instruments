# \<instance-parameter\> Element

Creates a named parameter that can be assigned once per modeler
instance.

:::: {#dev415891837syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<instance-parameter>`{.CodeLine}`\?[a-z]+[A-Za-z0-9]*(-[A-Za-z0-9]+)*`{.CodeLine}`</instance-parameter>`{.CodeLine}
:::
::::

::: {#dev415891837tn .Subhead}
## Type Notes {#type-notes .Name}

A parameter name, starting with a ? to indicate that it\'s not a
constant.
:::
