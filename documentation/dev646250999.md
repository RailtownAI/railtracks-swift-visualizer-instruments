# \<slice-type-hierarchy\> Element

The engineering type hierarchy that should be augmented by this
augmentation defined graphs and details.

:::: {#dev646250999syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<slice-type-hierarchy>`{.CodeLine}`(level{1, 4})`{.CodeLine}`</slice-type-hierarchy>`{.CodeLine}
:::
::::

The order of the slice types defined in it represents the position of
the augmented track in the hierarchy. It can specify the instrument
engineering type, but only at the top level of the types hierarchy.
