# Metal Event Engineering Type

Used as an adjective to describe a Metal event, Such as color encoded
frames or display stutters This is for uses like providing images that
help explain the type of the events.

:::: {#dev43188348us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `metal-event`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Graphics
  Display Width   70 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
