# Symbol Argument Engineering Type

Argument or return value signature. Typically an argument to a function
as it\'s expressed in symbolic constants rather than a numeric value,
such as \"R_OK\|W_OK\|X_OK\" or
\"NSStringEncodingConversionAllowLossy\".
