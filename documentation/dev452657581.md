# \<os-signpost-point-schema\> Element

Defines a point schema that is populated with data from os_signpost API
messages.

:::: {#dev452657581syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<os-signpost-point-schema>`{.CodeLine}`(id, title, owner?, purpose?, note?)(attribute*, event-type?, subsystem?, category?, name?, identifier?, pattern, timestamp-column?, primary-column{0, 2}, column*)`{.CodeLine}`</os-signpost-point-schema>`{.CodeLine}
:::
