# Visual Connection ID (old) Engineering Type

An ID for connections between the planes of a graph.

::::: {#dev81330366us .Subhead}
## Usage {#usage .Name}

::: Alert
**WARNING:** This engineering type is considered deprecated and should
not be used for new development.
:::

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `connection-uuid`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
:::::
