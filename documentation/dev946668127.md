# \<symbol-field\> Element

The field from a node column which will determine the symbol. This
should be an integer index into a typed array..

:::: {#dev946668127syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<symbol-field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</symbol-field>`{.CodeLine}
:::
::::

::: {#dev946668127tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
