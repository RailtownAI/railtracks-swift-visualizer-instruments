# Welcome to Developing Instruments

Instruments is a powerful tool for analyzing the performance of your
app. Apple provides dozens of instruments which are designed to work
with the operating system to collect and display data you need to tune
your code. However, when the data collected by the operating system
isn\'t enough, you can create an instrument that collects and displays
your own data. You can also create a custom view of the data Instruments
already collects.

In Xcode, you [create an instruments
project](devfd0adc59c.html#devfd0adc59c){.xRef .AppleTopic} from the
Instruments Package template. The project will contain an [instruments
package file](dev67cb5abd5.html#dev67cb5abd5){.xRef .Aside} that you
edit to define the instrument using the Instruments Package Definition
elements. The instrument will work closely with the logging and signpost
functions in the
[os](https://developer.apple.com/documentation/os){.URL} framework. The
project contains a single target that builds an instruments distribution
package.

![](Art/gs_instruments_project.png){height="274" width="600"}

Later, you can distribute your instrument to anyone working on your app.
The instruments distribution package contains no executable code, so you
can share it as a download on a website or email it to developers.
