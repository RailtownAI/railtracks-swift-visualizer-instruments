# \<package\> Element

Creates an installable package for Instruments to deploy custom
instrumentation

:::: {#dev13041708syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<package>`{.CodeLine}`(id, version?, title, owner, note?, import-schema*, import-augmentation*, define-trace-parameter*, (interval-schema | ktrace-interval-schema | os-signpost-interval-schema | point-schema | os-log-point-schema | os-signpost-point-schema | ktrace-point-schema)*, knowledge-source*, modeler*, augmentation*, instrument*, template{0, 30})`{.CodeLine}`</package>`{.CodeLine}
:::
