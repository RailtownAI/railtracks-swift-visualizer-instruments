# URLSession Engineering Type

A URLSession object and associated information.

:::: {#dev47317129us .Subhead}

::: {#dev47317129dc .Subhead}
## Display Conventions {#display-conventions .Name}

Sessions are displayed using the description given by the developer (if
present) and their internal id. Other attributes (e.g. whether a session
is shared or ephemeral) may be included as well.
:::

::: {#dev47317129ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

A combination of the internal session id, the given developer
description and additional metadata. The first slot holds the session
uuid, the second slot the developer specified background identifier
(only for background sessions) the third slot holds the user-readable
name of the session either specified by the developer
(\`session.sessionDescription\`) or generated by the modeler. the fourth
slot encodes a session type enum as a string, marking e.g. whether this
session is the \"shared\" session or is an \"ephemeral\" session. The
last and final slot contains a json-encoded dictionary with additional
metadata about the session for additional properties to enable
extensibility in the future. It\'s currently unused.
:::
