# Device Session ID Engineering Type

A device session identifier.

:::: {#dev65863841us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `device-session`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::

:::: {#dev65863841dc .Subhead}

:::
::::

::: {#dev65863841ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

These identifiers are used to create unique namespaces for process ids,
thread ids, and other operating system specific identifiers that cycle
at boot time. Each time a target is booted or detected, it should be
assigned a unique identifier.
:::
