# os_signpost Identifier Engineering Type

A 64-bit identifier that uniquely identifies a call to
os_signpost_interval_begin or os_signpost_interval_end.

:::: {#dev234029344us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `os-signpost-identifier`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Sentinel        zero
:::
::::

:::: {#dev234029344dc .Subhead}
## Display Conventions {#display-conventions .Name}

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev234029344ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

The value 0 and UINT64_MAX are illegal (i.e. OS_SIGNPOST_ID_NULL and
OS_SIGNPOST_ID_INVALID).
:::
