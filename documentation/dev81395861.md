# Label Engineering Type

Similar to a \"narrative\", which displays long formatted strings, the
formatted label uses the same approach but is intended for smaller
strings that uniquely label something.

:::: {#dev81395861us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `formatted-label`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   170 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  narrative       Value is a typed array, but displayed on a single line as a string.
:::
::::

::: {#dev81395861dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displayed the same as narratives in most cases. Each sub-portion of the
string can have an action menu, like a regular narrative.
:::
