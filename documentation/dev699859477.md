# \<engineering-type-track\> Element

Defines engineering type data track data source. When this Instrument is
present in the trace document, this data source is queried and matching
engineering type tracks are created.

:::: {#dev699859477syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<engineering-type-track>`{.CodeLine}`(table-ref?, hierarchy)`{.CodeLine}`</engineering-type-track>`{.CodeLine}
:::
::::
