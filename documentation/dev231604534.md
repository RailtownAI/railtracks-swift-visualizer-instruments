# \<column\> Element

Defines a column that will apply a function to the data falling into
this node of the aggregate.

:::: {#dev231604534syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<column>`{.CodeLine}`(title?, instance-by-parameter?, (choose-any | choose-unique | count | sum | min | max | average | std-dev | range | percent-of-capacity))`{.CodeLine}`</column>`{.CodeLine}
:::
