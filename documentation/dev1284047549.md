# \<label-format\> Element

Each instance of the histogram can have a different label, where %s is
the string value of the instance-by column\'s value.

:::: {#dev1284047549syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<label-format>`{.CodeLine}`.*`{.CodeLine}`</label-format>`{.CodeLine}
:::
::::

:::: {#dev1284047549e346686421 .Subhead}
## Usage Example {#usage-example .Name}

::: CodeLines
*`<!-- We want a separate histogram for each thread we see in the thread column-->`{.CodeLine}*`<histogram-template>`{.CodeLine}` <instance-by>thread</instance-by>`{.CodeLine}` `{.CodeLine}*`<!-- Label each graph something like "Worker Thread: 0x23984" -->`{.CodeLine}*` <label-format>Worker Thread: %s</label-format>`{.CodeLine}` `{.CodeLine}*`<!-- ... -->`{.CodeLine}*`</histogram-template>`{.CodeLine}
:::
