# Log Event Type Engineering Type

A string describing the type of log event.

:::: {#dev44171418us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `event-type`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   100 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  event           Value identifies an event and receives a special graph treatment.
:::
::::
