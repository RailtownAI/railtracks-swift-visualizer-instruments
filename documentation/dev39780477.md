# PMC Data Engineering Type

An array of PMC values read from the CPU.

::::: {#dev39780477us .Subhead}
## Usage {#usage .Name}

::: Alert
**WARNING:** This engineering type is considered experimental and not
ready for public adoption.
:::

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `pmc-events`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          CPU
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
:::::

:::: {#dev39780477dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displays a list of counter delta values, separated by commas.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev39780477ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

An array of counter deltas (i.e. changes since the last sample).
:::
