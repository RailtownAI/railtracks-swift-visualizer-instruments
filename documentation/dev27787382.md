# Hang Type Engineering Type

Encodes the type of hang (microhang, severe hang, etc.)

:::: {#dev27787382us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `hang-type`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
