# \<lane\> Element

When a value of \"slice-type\" is being graphed, the user will have the
option of adding this lane to that graph.

:::: {#dev433455490syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<lane>`{.CodeLine}`(title, table-ref, (slice-by-hierarchy), guide?, base-color?, (plot | plot-template | histogram | histogram-template){1, 3})`{.CodeLine}`</lane>`{.CodeLine}
:::
::::

:::: {#dev433455490el .Subhead}

| Element                                                                   | Description                                                                           |
