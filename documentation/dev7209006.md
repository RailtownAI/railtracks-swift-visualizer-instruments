# Event Name Engineering Type

A string describing the type of event. \"open\", \"close\", etc\... This
type is typically reserved for prototyping. More explicitly event types
should be created when possible.

:::: {#dev7209006us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `event`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   100 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  event           Value identifies an event and receives a special graph treatment.
:::
