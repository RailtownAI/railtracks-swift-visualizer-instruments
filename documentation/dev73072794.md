# kdebug Subclass Engineering Type

A kdebug subclass field value. This value, along with a kdebug-class,
provide a namespace for a kdebug-code.

:::: {#dev73072794us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-subclass`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev73072794dc .Subhead}
## Display Conventions {#display-conventions .Name}

Codes for kdebug are usually used for debugging, usually in hex.
