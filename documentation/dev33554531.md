# kdebug Code Engineering Type

A kdebug code field value.

:::: {#dev33554531us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-code`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev33554531dc .Subhead}
## Display Conventions {#display-conventions .Name}

Codes for kdebug are usually used for debugging, usually in hex.
:::

::: {#dev33554531ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

These are typically emitted from the kernel (or from user space via the
kernel). The mapping between names and code is context dependent based
on the class and subclass.
:::
