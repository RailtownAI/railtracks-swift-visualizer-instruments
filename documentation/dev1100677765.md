# \<field\> Element

The field from a node column which will determine the annotation. This
should be an integer index into a typed array.

:::: {#dev1100677765syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</field>`{.CodeLine}
:::
::::

::: {#dev1100677765tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
