# \<annotation-column\> Element

A column that provides additional metadata about the edge, such as a
backtrace. Data from annotation columns are displayed in the Extended
Detail when the associated edge is selected.

:::: {#dev871236172syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines

:::
::::

::: {#dev871236172tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
