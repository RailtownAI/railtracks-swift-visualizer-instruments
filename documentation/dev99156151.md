# Metal Device Engineering Type

The name of a Metal Device channel, such as Vertex. It varies depending
on the vendor and GPU architecture

  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Graphics
  Display Width   150 pt
