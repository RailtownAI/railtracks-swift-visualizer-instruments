# Process ID Engineering Type

A process id (pid).

:::: {#dev2687001us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `pid`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Bit Width       17 bits
  Sentinel        max
:::
::::

::: {#dev2687001dc .Subhead}
## Display Conventions {#display-conventions .Name}

During display, it may be possible to display the process name along
with the pid as long as it\'s not ambiguous.
:::

::: {#dev2687001ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This is a generic 32-bit process id. Typically a process object is
preferred since it connects the device session and process id together
so data between two attachments to a target can be properly separated.
:::
