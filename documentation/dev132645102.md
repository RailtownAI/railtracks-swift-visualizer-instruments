# CPU Event Counter Engineering Type

A value representing a graphics driver counter.

:::: {#dev132645102us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ---------------------
  Mnemonic        `cpu-event-counter`
  CLIPS Type      `INTEGER`
  Family          CPU
  Display Width   120 pt
  Bit Width       64 bits
  Sentinel        max
:::
::::

::: {#dev132645102ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This value is a meant to count the events for a given table row, which
usually means that the value is a delta from some epoch. This epoch is
usually the last sample, so the values will generally remain small.
64-bit max is the sentinel which could indicate that the counter was not
able to be sampled.
:::
