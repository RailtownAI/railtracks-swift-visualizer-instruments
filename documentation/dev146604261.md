# \<graph\> Element

Defines the graph, or track, that the instrument will present. There can
be several.

:::: {#dev146604261syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<graph>`{.CodeLine}`(title, purpose?, (lane-ref | lane){0, 10}, visit-on-selection?, selection-id?)`{.CodeLine}`</graph>`{.CodeLine}
:::
::::

:::: {#dev146604261el .Subhead}
## Elements {#elements .Name}

::: table-wrapper
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| Element                                                                   | Description                                                           |
+===========================================================================+=======================================================================+
| [title](dev193855764.html#dev193855764){.xRef .AppleTopic}                | The title of the graph mode.                                          |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| [purpose](dev238092608.html#dev238092608){.xRef .AppleTopic}              | The reason this graph should be used. Typically presented as a        |
|                                                                           | tooltip.                                                              |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| [lane-ref](dev245956906.html#dev245956906){.xRef .AppleTopic}             | Reference to a lane definition that should be copied from an          |
|                                                                           | enclosing context. It should refer to a lane contained in the         |
|                                                                           | Instrument definition or an engineering track level placed above the  |
|                                                                           | currently defined level.                                              |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| [lane](dev170852594.html#dev170852594){.xRef .AppleTopic}                 | Graphs are laid out vertically into 1 or more lanes.                  |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| [visit-on-selection](dev771228222.html#dev771228222){.xRef .AppleTopic}   | Specifies detail element name that should be visited when graph is    |
|                                                                           | selected by the user.                                                 |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| [selection-id](dev530448836.html#dev530448836){.xRef .AppleTopic}         | Specifies selection identifier of the graph. Allows for synchronizing |
|                                                                           | selection between different graphs present in the document on         |
|                                                                           | differing hierarchy levels.                                           |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
:::
