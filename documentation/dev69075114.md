# Configuration String Value Engineering Type

A value string used in a key/value configuration table for modelers to
receive complex configurations. This stores the \"value\" portion of a
configuration pair when the value is a string.

:::: {#dev69075114us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `string-value`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
