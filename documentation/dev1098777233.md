# \<table-ref\> Element

The data table that the engineering types will be created from. Needs to
be used if any level in the hierarchy is dynamic, expressed by
\'column\' element.

:::: {#dev1098777233syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<table-ref>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</table-ref>`{.CodeLine}
:::
::::

::: {#dev1098777233tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
:::
