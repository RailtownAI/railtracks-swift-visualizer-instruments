# GPU State Engineering Type

Describes the current state of the GPU

:::: {#dev38469763us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `gpu-state`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Graphics
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  state           Value identifies a state and receives a special graph treatment.
:::
::::
