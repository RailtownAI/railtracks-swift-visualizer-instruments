# \<create-parameter\> Element

Creates a parameter specific to this instrument. Parameters show up in
the UI and command line as recording options.

:::: {#dev494862765syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<create-parameter>`{.CodeLine}`(name, guide?, (boolean-value | enumeration | meta))`{.CodeLine}`</create-parameter>`{.CodeLine}
:::
::::

:::: {#dev494862765el .Subhead}
## Elements {#elements .Name}

::: table-wrapper
+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
| Element                                                               | Description                                                           |
+=======================================================================+=======================================================================+
| [name](dev240648482.html#dev240648482){.xRef .AppleTopic}             | The name of the parameter, unique with the implied scope of the       |
|                                                                       | parameter.                                                            |
+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
| [guide](dev262013231.html#dev262013231){.xRef .AppleTopic}            | A note that documentation tools may extract when creating a user\'s   |
|                                                                       | guide.                                                                |
+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
| [boolean-value](dev451936665.html#dev451936665){.xRef .AppleTopic}    | Defines a parameter which can be 1 (true) or 0 (false).               |
+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
| [enumeration](dev404226440.html#dev404226440){.xRef .AppleTopic}      | Defines a parameter that can be one of list of values.                |
+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
| [meta](dev241828136.html#dev241828136){.xRef .AppleTopic}             | Defines a parameter that requires an implied UI contract defined by a |
|                                                                       | type-id and generic parameter string.                                 |
+-----------------------------------------------------------------------+-----------------------------------------------------------------------+
:::
