# Frames Per Second Engineering Type

Frame per second. A common metric used to represent the average number
of frames an app is rendering per second.

:::: {#dev1835030us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ---------------------------------------------------------------
  Mnemonic        `fps`
  CLIPS Type      `FLOAT`
  Family          Graphics
  Display Width   80 pt
  context-free    Values have the same meaning regardless of where they appear.
:::
::::

::: {#dev1835030dc .Subhead}
## Display Conventions {#display-conventions .Name}

Usually represented by a 1 decimal place float and an FPS suffix
:::
