# Create an instrument based on signpost data

A simple way to get data into Instruments is to use the
`os_signpost_interval` APIs in the
[os](https://developer.apple.com/documentation/os){.URL} framework.
These APIs allow you to mark the start and end of interesting points in
your app and attach metadata in the form of format strings and
arguments. You can capture that metadata and structure it into a graph
and table in Instruments.

You need to [create an Instruments Package
project](devfd0adc59c.html#devfd0adc59c){.xRef .AppleTopic} before you
can perform some of these steps.

:::: {#dev0edc6270b .Task}
## In the app's code, create signpost intervals {#in-the-apps-code-create-signpost-intervals .Name role="button" aria-controls="aria-dev0edc6270b" aria-expanded="true"}

::: {#aria-dev0edc6270b .TaskBody role="region" aria-hidden="false"}
1.  Choose or create a logging handle (*os_log_t*) for the subsystem and
    category you want to trace. These are created with the
    `os_log_create(…)` function.

2.  Mark a function or block of code you'd like to time or would like to
    know when it starts and ends.

    - To start the interval, call the `os_signpost_interval_begin(…)`
      function using an appropriate identifier and name for the
      interval.

    - To end the interval, call the `os_signpost_interval_end(…)`
      function using the same log handle, identifier, and name supplied
      to the start call.
:::
::::

:::: {#dev2a4184c0d .Task}
## In the instruments package, create an os-signpost-interval-schema {#in-the-instruments-package-create-an-os-signpost-interval-schema .Name role="button" aria-controls="aria-dev2a4184c0d" aria-expanded="true"}

::: {#aria-dev2a4184c0d .TaskBody role="region" aria-hidden="false"}
1.  Drag the `os-signpost-interval-schema` code snippet from the Code
    Snippet Library somewhere into the [instruments package
    file](dev67cb5abd5.html#dev67cb5abd5){.xRef .Aside} before the
    modelers and instruments are defined. If this is a new file, drop it
    after the `<owner>` element.

2.  Enter the subsystem and category of the logging handle that you
    choose for your signposts.

3.  Enter the name of the signpost interval you created and want to
    record.

4.  Capture the arguments you need from the signpost format string of
    the start message.

5.  Capture the arguments you need from the signpost format string of
    the end message.

6.  Drag a `column-from-expression` code snippet from the Code Snippet
    Library into the `os-signpost-interval-schema` element at the end.

7.  For each column you add, enter the name, title, and engineering type
    you want the column to have.

8.  For each column, set the expression, usually from a captured
    argument value in the start or end pattern.
:::
::::

:::: {#devc1d7419ce .Task}
## In the instruments package, create a custom instrument to display your data {#in-the-instruments-package-create-a-custom-instrument-to-display-your-data .Name role="button" aria-controls="aria-devc1d7419ce" aria-expanded="true"}

::: {#aria-devc1d7419ce .TaskBody role="region" aria-hidden="false"}
1.  Drag an instrument code snippet from the Code Snippet Library into
    the [instruments package file](dev67cb5abd5.html#dev67cb5abd5){.xRef
    .Aside}.

2.  Enter the required tokens in the snippet

3.  Drag in a create-table code snippet from the Code Snippet Library.

4.  Enter the schema-ref of the create-table element with the id of the
    schema you defined for your os-signpost-interval-schema.

5.  Define a graph for your interval data.

6.  Define a detail view for your interval data.
:::
::::

:::: {#dev60b7fd280 .Task}
## Build and test the instrument {#build-and-test-the-instrument .Name role="button" aria-controls="aria-dev60b7fd280" aria-expanded="true"}

::: {#aria-dev60b7fd280 .TaskBody role="region" aria-hidden="false"}
1.  Build and run the instruments package target.

2.  When Instruments launches, select the Blank template to create an
    empty document.

3.  Drag the new instrument in from the Library.

4.  Select your app with the embedded signpost calls as the target and
    press record.

5.  Make your app emit the interval you just created and see if you see
    what you'd expect in Instruments.
:::
::::
