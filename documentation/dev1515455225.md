# \<outline-field\> Element

The field on the node object from which the boolean value will be
derived that decides whether or not to show the node in the outline
view.

:::: {#dev1515455225syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<outline-field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</outline-field>`{.CodeLine}
:::
::::

::: {#dev1515455225tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
