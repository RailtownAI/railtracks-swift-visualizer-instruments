# Display VSync Event Engineering Type

A vsync event. Normally just VSYNC. When APT is enabled, the vsync track
also contains APT events.

:::: {#dev62390428us .Subhead}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `vsync-event`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Graphics
  Display Width   55 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
