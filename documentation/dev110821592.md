# Mach Absolute Time Engineering Type

A value from mach_absolute_time(). This value is not relative to the
start of the trace. Typically it\'s used for timing event durations.
Sometimes it\'s is used as a semi-unique ID.

:::: {#dev110821592us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ----------------------
  Mnemonic        `mach-absolute-time`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   100 pt
  Bit Width       50 bits
:::
::::

::: {#dev110821592dc .Subhead}
## Display Conventions {#display-conventions .Name}

The UI will attempt to display the timestamp as time of day.
