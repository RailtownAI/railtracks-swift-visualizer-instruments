# System Call Engineering Type

The name assigned by the OS to a system call. This name may or may not
map to an exposed system call API.

:::: {#dev22151247us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `syscall`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          I/O
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  event           Value identifies an event and receives a special graph treatment.
:::
::::
