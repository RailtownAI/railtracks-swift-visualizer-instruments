# kdebug String Engineering Type

String ID for strings parsed out of a kdebug stream. KDebug traces have
a mechanism for providing string/ID pairs. This is the 64-bit number
that represents that string.

:::: {#dev57933981us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-string`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
