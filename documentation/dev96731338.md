# Size in Pixels Engineering Type

A size in pixels that a particular piece of geometry is.

:::: {#dev96731338us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `size-in-pixels`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          Graphics
  Display Width   100 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev96731338dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displayed as a tuple, separated by commas
:::

::: {#dev96731338ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This is implemented as a 64-bit integer array, so the number of
dimensions is arbitrary, by it\'s likely that (width, height) will be
the most common use.
:::
