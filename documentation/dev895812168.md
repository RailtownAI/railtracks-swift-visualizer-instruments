# \<color-field\> Element

The field from a node column which will determine the color. This should
be an integer index into a typed array.

:::: {#dev895812168syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<color-field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</color-field>`{.CodeLine}
:::
::::

::: {#dev895812168tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
