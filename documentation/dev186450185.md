# Displayed Surface Swap Engineering Type

An identifier representing the displayed surface swap transaction.

:::: {#dev186450185us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `displayed-surface-swap`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Signed          false
  Sentinel        max
:::
::::
