# Combine DataTap Engineering Type

Name for a DataTap inside a Combine Graph used for logging data output
in Combine.

:::: {#dev126681294us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `combine-datatap-name`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   400 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
