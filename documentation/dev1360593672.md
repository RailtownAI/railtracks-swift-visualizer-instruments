# \<column-to-sum\> Element

Specifies which column should be used to compute the sum, before
dividing by \"capacity\".

:::: {#dev1360593672syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<column-to-sum>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</column-to-sum>`{.CodeLine}
:::
::::

::: {#dev1360593672tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
:::
