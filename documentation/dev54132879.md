# Thread State Engineering Type

A thread state.

:::: {#dev54132879us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `thread-state`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
