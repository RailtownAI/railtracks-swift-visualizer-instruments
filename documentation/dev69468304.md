# \<modeler\> Element

Defines a modeler or rule system that transforms one type of data into
another.

:::: {#dev69468304syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<modeler>`{.CodeLine}`(id, title, owner?, purpose, (production-system | built-in), instance-parameter*, output{1, unbounded})`{.CodeLine}`</modeler>`{.CodeLine}
:::
::::

:::: {#dev69468304el .Subhead}

| Element                                                                   | Description                                                           |

|                                                                           | across all packages.                                                  |

| [title](dev151847150.html#dev151847150){.xRef .AppleTopic}                | The title that will be used to identify this modeler.                 |

| [purpose](dev191103258.html#dev191103258){.xRef .AppleTopic}              | Describes the situation when this modeler is instantiated.            |
