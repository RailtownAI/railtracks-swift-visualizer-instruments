# \<percent-of-capacity\> Element

Totals a column value, divides by the capacity constant, and multiplies
by 100.

:::: {#dev759104016syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<percent-of-capacity>`{.CodeLine}`(column-to-sum, capacity)`{.CodeLine}`</percent-of-capacity>`{.CodeLine}
:::
::::

:::: {#dev759104016el .Subhead}
## Elements {#elements .Name}

::: table-wrapper
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| Element                                                                   | Description                                                           |
+===========================================================================+=======================================================================+
| [column-to-sum](dev1360593672.html#dev1360593672){.xRef .AppleTopic}      | Specifies which column should be used to compute the sum, before      |
|                                                                           | dividing by \"capacity\".                                             |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
| [capacity](dev1102512762.html#dev1102512762){.xRef .AppleTopic}           | A constant representing the capacity, which is the sum we define to   |
|                                                                           | be 100%                                                               |
+---------------------------------------------------------------------------+-----------------------------------------------------------------------+
:::
