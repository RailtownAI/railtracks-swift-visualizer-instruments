# \<color-from\> Element

Determine the color based on this column rather than value-from\'s
column.

:::: {#dev251593037syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<color-from>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</color-from>`{.CodeLine}
:::
::::

::: {#dev251593037tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
:::
