# GPU Driver Segment ID Engineering Type

Driver submissions are comprised of 1 or more segments, each with their
own ID.

:::: {#dev148308205us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `gpu-driver-segment`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
