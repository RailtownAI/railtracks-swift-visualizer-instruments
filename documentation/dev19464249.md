# Socket Address Engineering Type

A socket address structure (struct sockaddr).

:::: {#dev19464249us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `sockaddr`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          I/O
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev19464249dc .Subhead}
## Display Conventions {#display-conventions .Name}

The socket address will be resolved using the standard inet_ntop
initially. The UI may update the field after reverse DNS look up occurs
and there is a textual host name.
:::

::: {#dev19464249ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as a sockaddr structure in C. Must be decoded with the Darwin
networking APIs.
:::
