# Region of Interest Kind Engineering Type

Describes the type of a region of interest, such as \"Signpost\" or
\"Life Cycle Event\".

:::: {#dev28442727us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `roi-kind`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
