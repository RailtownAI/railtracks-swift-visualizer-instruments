# Structure needed convert a Mach absolute time in to seconds Engineering Type

Can be multiplied with a Mach absolute time in order to convert the
value into seconds.

:::: {#dev104202422us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------
  Mnemonic        `mach-timebase-info`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev104202422dc .Subhead}
## Display Conventions {#display-conventions .Name}

Usually displayed as a n/d value for debugging purposes
:::

::: {#dev104202422ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as a uint64 where the MSBs are the numerator and the LSBs are
the denominator.
:::
