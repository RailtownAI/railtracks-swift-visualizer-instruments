# \<plot-template\> Element

Like \"plot\", except it will automatically create slices for each value
in \"instance-by\".

:::: {#dev592773614syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<plot-template>`{.CodeLine}`(instance-by, label-format?, slice*, best-for-resolution{0, 3}, value-from, color-from?, priority-from?, label-from?, (qualified-by | disable-implicit-qualifier)?qualifier-treatment*, containment-level-from?, (visit-on-focus | disable-visit-on-focus)?, (peer-group | ignore-peer-group)?)`{.CodeLine}`</plot-template>`{.CodeLine}
:::
