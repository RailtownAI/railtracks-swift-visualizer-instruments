# \<time-slice\> Element

Creates a table view in the detail area that only displays data that
intersects the inspection head.

:::: {#dev247464238syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<time-slice>`{.CodeLine}`(title, purpose?, guide?, table-ref, guide?, slice*, visit-on-focus?, empty-content-suggestion?, stabilizer-column?, (add-all-columns | add-all-columns-except | column | hidden-column | annotation-column){1, 64})`{.CodeLine}`</time-slice>`{.CodeLine}
:::
