# \<name\> Element

Specifies the unique name of the parameter to import.

:::: {#dev211419412syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<name>`{.CodeLine}`\?[a-z]+[A-Za-z0-9]*(-[A-Za-z0-9]+)*`{.CodeLine}`</name>`{.CodeLine}
:::
::::

::: {#dev211419412tn .Subhead}
## Type Notes {#type-notes .Name}

A parameter name, starting with a ? to indicate that it\'s not a
constant.
:::

:::: {#dev211419412e695993821 .Subhead}
## Syntax Example {#syntax-example .Name}

::: CodeLines
`?target-pid`{.CodeLine}
:::
::::

:::: {#dev211419412e346686421 .Subhead}
## Usage Example {#usage-example .Name}

*`<!-- Parameters start with the ? character to distinguish them from literals -->`{.CodeLine}*`<name>?target-pid</name>`{.CodeLine}
