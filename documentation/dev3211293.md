# TID Engineering Type

Generic thread id.

:::: {#dev3211293us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `tid`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Sentinel        max
:::
::::

::: {#dev3211293dc .Subhead}
## Display Conventions {#display-conventions .Name}

TIDs are often good enough to identify a thread, so for display
purposes, a well-known name may be substituted for this 64-bit integer,
if it is available and unambiguous.
:::

::: {#dev3211293ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

It is unclear, when using this type, which domain the id applies to. It
could be a Mach or POSIX thread id.
:::
