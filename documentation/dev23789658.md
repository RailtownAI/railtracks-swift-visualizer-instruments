# Configuration ID Engineering Type

Sometimes modelers require a sophisticated configuration to be fed to
them via an Analysis Core table.

:::: {#dev23789658us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `config-id`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Bit Width       22 bits
:::
::::

::: {#dev23789658ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This identifier is a unique ID that allows the modeler to know which
key/value pairs go together to form a specific configuration element.
This is similar to a record identifier, or a tuple identifier.
:::
