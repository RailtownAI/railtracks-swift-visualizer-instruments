# Visual Connection Attributes Engineering Type

64-bits of data used to determine how this visual connection should be
displayed.

:::: {#dev78381233us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `connection-meta`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

:::: {#dev78381233dc .Subhead}
## Display Conventions {#display-conventions .Name}

The fields of this attribute set determine how to visually render a
connection

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev78381233ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

The bits have yet to be defined, but will determine things like arrow
head style, connecting to the top or bottom of the plane, etc\...
:::
