# \<priority-from\> Element

Determine the value priority based on this column. This specifies
precedence in a drawing scenario, if values are resolved to be drawn in
the same area.

:::: {#dev336527760syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<priority-from>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</priority-from>`{.CodeLine}
:::
::::

::: {#dev336527760tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
