# Location Event Engineering Type

An event from a core location manager object, such as a \"requested
accuracy changed\" event.

:::: {#dev69796002us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `location-event`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  event           Value identifies an event and receives a special graph treatment.
:::
