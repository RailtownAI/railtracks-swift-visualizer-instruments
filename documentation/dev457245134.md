# \<visit-on-focus\> Element

The title of a detail view to visit when the user attempts to focus on a
specific row.

:::: {#dev457245134syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<visit-on-focus>`{.CodeLine}`.*`{.CodeLine}`</visit-on-focus>`{.CodeLine}
:::
::::

::: {#dev457245134tn .Subhead}
## Type Notes {#type-notes .Name}

The title of another defined detail view, like a list, to visit when the
user clicks the focus button of an aggregate.
:::
