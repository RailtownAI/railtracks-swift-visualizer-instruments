# Text Segment Address Engineering Type

A text segment address. There is no process address space associated
with this address.

:::: {#dev62914707us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `text-address`
  CLIPS Type      `INTEGER`
  Family          CPU
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev62914707dc .Subhead}
## Display Conventions {#display-conventions .Name}

Typically displayed numerically. Because this text address does not have
an associated process, it cannot be converted to a symbol at run time.
:::
