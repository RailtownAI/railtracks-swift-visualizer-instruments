# \<lane\> Element

Graphs are laid out vertically into 1 or more lanes.

:::: {#dev170852594syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<lane>`{.CodeLine}`(title, table-ref, guide?, base-color?, (plot | plot-template | histogram | histogram-template){1, 3})`{.CodeLine}`</lane>`{.CodeLine}
:::
::::
