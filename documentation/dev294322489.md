# \<define-trace-parameter\> Element

Defines a parameter at the trace scope. These parameters are often
called Recording Settings.

:::: {#dev294322489syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<define-trace-parameter>`{.CodeLine}`(name, guide?, (boolean-value | enumeration | meta))`{.CodeLine}`</define-trace-parameter>`{.CodeLine}
:::
::::
