# Medium-length String Engineering Type

Generic string value representing a medium-length string. The only
difference to \`string\` is that it\'s default column-width is 2/3 of
\`string\` by default.

:::: {#dev159777033us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `medium-length-string`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev159777033dc .Subhead}
## Display Conventions {#display-conventions .Name}

This string could be anything, but if you need to encode longer strings,
take a look at \`string\`.
:::

::: {#dev159777033ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This should only be used for prototyping purposes when the other
engineering types aren\'t a good match for your implementation.
:::
