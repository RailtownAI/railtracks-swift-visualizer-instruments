# 64-bit Unsigned Integer Array Engineering Type

An array of 64-bit unsigned integers.

:::: {#dev83886277us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `uint64-array`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   500 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev83886277dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displayed up to a certain length determined by the UI then truncated.
Generally these are not displayed except when debugging.
:::

::: {#dev83886277ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as an array of uint64 entries.
