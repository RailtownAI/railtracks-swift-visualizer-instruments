# Short String Engineering Type

Generic string value representing a short string. The only difference to
\`string\` is that it\'s default column-width is 1/3 of \`string\` by
default.

:::: {#dev74121403us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `short-string`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   100 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev74121403dc .Subhead}
## Display Conventions {#display-conventions .Name}

This string could be anything, but if you need to encode longer strings,
take a look at \`string\` or \`medium-length-string\`.
:::

::: {#dev74121403ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This should only be used for prototyping purposes when the other
engineering types aren\'t a good match for your implementation.
:::
