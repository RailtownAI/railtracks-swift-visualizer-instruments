# \<histogram-template\> Element

Like \"histogram\", except it will automatically create slices for each
value in \"instance-by\"

:::: {#dev750191133syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<histogram-template>`{.CodeLine}`(instance-by, label-format?, slice*, best-for-resolution{0, 3}, nanoseconds-per-bucket, (choose-any | choose-unique | count | sum | min | max | average | std-dev | range | percent-of-capacity), (visit-on-focus | disable-visit-on-focus)?, (peer-group | ignore-peer-group)?)`{.CodeLine}`</histogram-template>`{.CodeLine}
:::
