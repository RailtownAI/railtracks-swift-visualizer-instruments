# Visual Connection Route Engineering Type

An string identifying the type of connection chain. This is useful for
identifying related types of connections, allowing for UI operations
like filtering the visible set by this name.

:::: {#dev94699733us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `connection-route`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
