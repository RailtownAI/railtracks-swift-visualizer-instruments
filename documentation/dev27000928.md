# kdebug Argument Engineering Type

A kdebug code argument value.

:::: {#dev27000928us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-arg`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   135 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev27000928dc .Subhead}
## Display Conventions {#display-conventions .Name}

These arguments are arbitrary and user-defined. The formatting is
hexadecimal by default, but the user should be able to format with any
simple integer formatter because it is such a generic type.
:::
