# \<id\> Element

A unique id in reverse DNS notation that globally identifies your
instrument.

:::: {#dev170918154syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<id>`{.CodeLine}`[a-zA-Z]+[a-zA-Z0-9\-\.]*[a-zA-Z0-9]+`{.CodeLine}`</id>`{.CodeLine}
:::
::::

:::: {#dev170918154e695993821 .Subhead}
## Syntax Example {#syntax-example .Name}

::: CodeLines
`com.apple.dt.instruments`{.CodeLine}
:::
::::

:::: {#dev170918154e346686421 .Subhead}
