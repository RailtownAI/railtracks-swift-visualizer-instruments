# \<qualified-by\> Element

The column that can be used to separate overlapping or ambiguous table
rows being graphed.

:::: {#dev285933897syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<qualified-by>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</qualified-by>`{.CodeLine}
:::
::::

::: {#dev285933897tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
