# kdebug Function Engineering Type

Determines if the corresponding kdebug-code is a start/end/point.

:::: {#dev35586166us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-func`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   30 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  Bit Width       2 bits
:::
::::
