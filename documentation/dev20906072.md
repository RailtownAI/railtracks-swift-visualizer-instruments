# Version Number Engineering Type

A single numerical version number. This engineering unit is often used
with an capability for example to indicate what version a capability
supports.

:::: {#dev20906072us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------
  Mnemonic        `version`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  identifier      Value is treated as an identifier.
