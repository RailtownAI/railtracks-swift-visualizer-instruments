# Displayed Surface I/O Surface Engineering Type

Each displayed surface swap or vsync event has up to three IOSurfaces
associated with it.

:::: {#dev313065813us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `displayed-surface-io-surface`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Signed          false
  Sentinel        max
:::
::::

::: {#dev313065813dc .Subhead}
## Display Conventions {#display-conventions .Name}

Should be displayed as a hex value where -1 is treated as the
non-surface sentinel
:::
