# Capability ID Engineering Type

A string identifier that indicates a target\'s capability. For example,
a target device which is running macOS exports the capability
\"com.apple.osx\".

:::: {#dev17891401us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `capability`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
