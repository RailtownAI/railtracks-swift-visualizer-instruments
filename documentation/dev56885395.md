# \<owner\> Element

Describes who maintains the distribution and possibly how to find
updates.

:::: {#dev56885395syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<owner>`{.CodeLine}`(name, email?, radar-component?)`{.CodeLine}`</owner>`{.CodeLine}
:::
::::

:::: {#dev56885395el .Subhead}
## Elements {#elements .Name}

::: table-wrapper
+---------------------------------------------------------------------------+-------------------------------------------------------+
| Element                                                                   | Description                                           |
+===========================================================================+=======================================================+
| [name](dev55181448.html#dev55181448){.xRef .AppleTopic}                   | Name of the team or individual who maintains the      |
|                                                                           | component.                                            |
+---------------------------------------------------------------------------+-------------------------------------------------------+
| [email](dev63242383.html#dev63242383){.xRef .AppleTopic}                  | E-mail address where the maintainers of this          |
|                                                                           | component can be reached.                             |
+---------------------------------------------------------------------------+-------------------------------------------------------+
| [radar-component](dev211616031.html#dev211616031){.xRef .AppleTopic}      | Apple\'s Radar component where bugs can be filed      |
|                                                                           | against this component.                               |
+---------------------------------------------------------------------------+-------------------------------------------------------+
:::
