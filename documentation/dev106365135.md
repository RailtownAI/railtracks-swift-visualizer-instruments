# Mach-O VM Offset Engineering Type

A byte offset into the virtual memory layout of a Mach-O file\'s
loadable segments.

:::: {#dev106365135us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- --------------------
  Mnemonic        `mach-o-vm-offset`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   80 pt
:::
::::

::: {#dev106365135ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as a 32-bit integer to save space. Mach-O virtual memory layout
is currently limited to 4GiB.
