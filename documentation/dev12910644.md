# Thread Engineering Type

A thread.

:::: {#dev12910644us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `thread`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   220 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev12910644dc .Subhead}
## Display Conventions {#display-conventions .Name}

Thread objects typically are presented with a name that reflects the
bottom of their callstack, and the process from which they are attached
is usually included as well, if the UI would otherwise be ambiguous.
:::

::: {#dev12910644ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as an array, the first slot holding a 64-bit TID and the second
slot holding an iid for the process.
:::
