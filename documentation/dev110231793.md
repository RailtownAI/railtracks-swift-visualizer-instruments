# Instrument Type Engineering Type

The unique identifier for an instrument type, such as
\"com.apple.dt.time-profiler\".

:::: {#dev110231793us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `instrument-type`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   400 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::

::: {#dev110231793dc .Subhead}
## Display Conventions {#display-conventions .Name}

An instrument identifier used as a reference, usually internally.
:::
