# \<beta\> Element

When true, hides the instrument from the Library. The instrument still
appears in trace and tracetemplate files.

:::: {#dev206831897syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<beta>`{.CodeLine}`true | false`{.CodeLine}`</beta>`{.CodeLine}
:::
::::
