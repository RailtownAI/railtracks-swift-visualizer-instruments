# Visual ID Chain Engineering Type

An array of 64-bit unique identifiers (per-core) that aids in visually
connecting various IDs to one another.

:::: {#dev135397590us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `visual-uuid-chain`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

:::: {#dev135397590dc .Subhead}
## Display Conventions {#display-conventions .Name}

Part of the visual connections machinery.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
