# Data Engineering Type

An untyped array of bytes.

:::: {#dev2228249us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `data`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev2228249dc .Subhead}
## Display Conventions {#display-conventions .Name}

Since the data is untyped, just the length and the first few bytes will
be displayed in the short form. Longer forms may provide a long run of
hex values indicating the bytes.
:::

::: {#dev2228249ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as an array of uint64 entries, where the first entry is the byte
length. The following entries are \"eight-byte-array-le\" values, which
means that when viewed in memory the values are in the correct order,
but when viewed as a 64-bit entry, they\'re loaded backwards, where the
first byte in memory is in the least significant bits of the integer.
:::
