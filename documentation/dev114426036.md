# Metal Object Label Engineering Type

The metal framework assigns object labels to its various object types
for tracking them.

:::: {#dev114426036us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `metal-object-label`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Graphics
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::
