# Metal Encoder ID Engineering Type

The GPU driver assigns an ID to each Metal encoder.

:::: {#dev89391282us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `metal-encoder-id`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
