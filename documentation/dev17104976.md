# String Engineering Type

Generic string value.

:::: {#dev17104976us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `string`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

## Display Conventions {#display-conventions .Name}

sizing.
:::

engineering types aren\'t a good match for your implementation.
