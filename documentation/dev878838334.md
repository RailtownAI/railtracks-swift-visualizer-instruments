# \<node-format\> Element

Information about the format of the objects contained in the Source Node
Column and the Destination Node Column.

:::: {#dev878838334syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<node-format>`{.CodeLine}`(label-field?, identifier-field?, image-field?, outline-field?, annotation{0, 20})`{.CodeLine}`</node-format>`{.CodeLine}
:::
::::
