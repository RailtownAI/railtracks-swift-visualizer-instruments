# Energy Impact Engineering Type

A qualitative description of how much something is contributing to
energy usage or battery drain.

:::: {#dev63504527us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `energy-impact`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Energy
  Display Width   70 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  state           Value identifies a state and receives a special graph treatment.
:::
::::
