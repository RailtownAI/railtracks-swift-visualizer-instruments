# Layout ID Engineering Type

For modelers that perform layout for overlapping regions, this id acts
as a numerically sortable indicator as to which \"lane\" this row should
be graphed in such that it will not visually overlap with anything near
it.

:::: {#dev35061890us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------
  Mnemonic        `layout-id`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   70 pt
  identifier      Value is treated as an identifier.
  Bit Width       22 bits
:::
::::
