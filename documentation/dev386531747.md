# \<rule-path\> Element

A path relative to the location of this file where a rule system in the
CLIPS language can be found.

:::: {#dev386531747syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<rule-path>`{.CodeLine}`/?[^/]+(/[^/]+)*`{.CodeLine}`</rule-path>`{.CodeLine}
:::
::::

::: {#dev386531747tn .Subhead}
## Type Notes {#type-notes .Name}

A relative or absolute file path.
