# GPU Power State Engineering Type

A state string describing the power state of the GPU.

:::: {#dev115998955us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `gpu-power-state`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          Energy
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  state           Value identifies a state and receives a special graph treatment.
:::
::::
