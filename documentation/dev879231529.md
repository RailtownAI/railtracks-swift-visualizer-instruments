# \<label-field\> Element

The field from a node column which will determine the label. This should
be an integer index into a typed array.

:::: {#dev879231529syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<label-field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</label-field>`{.CodeLine}
:::
::::

::: {#dev879231529tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
:::
