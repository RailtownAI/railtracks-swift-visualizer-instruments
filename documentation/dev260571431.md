# Account Engineering Type

Number used to identify an account, e.g. account 1 vs. account 2.

:::: {#dev260571431us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `account-numeric-identifier`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   30 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Bit Width       8 bits
  Sentinel        max
:::
::::

::: {#dev260571431ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This identifier is used mainly for 8 bit numbers.
:::
