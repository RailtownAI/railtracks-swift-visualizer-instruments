# \<column\> Element

A reference to the name of a column that will be queried for the
engineering type track identity.

:::: {#dev1742930766syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<column>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</column>`{.CodeLine}
:::
::::

::: {#dev1742930766tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
