# Metal Command Buffer ID Engineering Type

The GPU driver assigns an ID to each Metal command buffer.

:::: {#dev191627526us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `metal-command-buffer-id`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::
