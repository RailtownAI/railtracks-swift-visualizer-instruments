# System Call Argument Engineering Type

An argument supplied to a system call.

:::: {#dev52625545us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ---------------
  Mnemonic        `syscall-arg`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   150 pt
:::
::::

::: {#dev52625545dc .Subhead}
## Display Conventions {#display-conventions .Name}

These arguments are arbitrary and system-defined. The formatting is
hexadecimal by default, but the user should be able to format with any
simple integer formatter because it is such a generic type.
:::
