# \<import-from-file\> Element

Imports a template from a Save As Template\... action.

:::: {#dev433848741syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<import-from-file>`{.CodeLine}`/?[^/]+(/[^/]+)*\.tracetemplate`{.CodeLine}`</import-from-file>`{.CodeLine}
:::
::::

::: {#dev433848741tn .Subhead}
## Type Notes {#type-notes .Name}

A relative or absolute file path to a trace template.
:::

:::: {#dev433848741e695993821 .Subhead}
## Syntax Example {#syntax-example .Name}

::: CodeLines
`templates/Time Profiler (example).tracetemplate`{.CodeLine}
:::
::::

:::: {#dev433848741e346686421 .Subhead}
## Usage Example {#usage-example .Name}
