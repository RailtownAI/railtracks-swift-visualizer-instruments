# \<slice-by-column\> Element

A column in the table-ref\'s schema that is of the according slice-type
specified in augmentation and will be used as a filter.

:::: {#dev508101067syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<slice-by-column>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</slice-by-column>`{.CodeLine}
:::
::::

::: Alert
**Tip:** For best performance, the slice-by should be a primary column
when possible.
:::

::: {#dev508101067tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
:::
