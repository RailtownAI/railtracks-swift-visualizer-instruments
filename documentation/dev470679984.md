# \<qualifier-treatment\> Element

Specifies how the sub-lane for the qualified value behaves and appears
visually.

:::: {#dev470679984syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<qualifier-treatment>`{.CodeLine}`(equals?, highlight?, walkable?)`{.CodeLine}`</qualifier-treatment>`{.CodeLine}
:::
::::
