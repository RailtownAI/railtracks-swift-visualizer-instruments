# \<slice\> Element

Restricts the input of the plot.

:::: {#dev153026799syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<slice>`{.CodeLine}`(when?, column, equals)`{.CodeLine}`</slice>`{.CodeLine}
:::
::::

::: {#dev153026799tn .Subhead}
## Type Notes {#type-notes .Name}

Narrows the data set from a table for a display or graph.
:::

::: Alert
**Tip:** For best performance, the column should be a primary column
when possible.
:::
