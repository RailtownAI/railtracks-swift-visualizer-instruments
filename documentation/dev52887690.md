# Row ID Engineering Type

Synthetic row id given to data as it\'s inserted into Analysis Core
tables.

::::: {#dev52887690us .Subhead}
## Usage {#usage .Name}

::: Alert
**WARNING:** This engineering type is considered deprecated and should
not be used for new development.
:::

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `row-number`
  CLIPS Type      `INTEGER`
  Family          Internal
  Display Width   100 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
:::::

::: {#dev52887690dc .Subhead}
## Display Conventions {#display-conventions .Name}

This generally should not be shown on a UI. This type is not something
that should appear in a schema. It\'s purpose is to have a unique key
that makes each row in a table unique. The value, if displayed, is
useful only to Instruments\' developers for debugging.
:::
