# Object Graph Node Engineering Type

A node that can be displayed in an Object Graph detail view.

:::: {#dev4980769us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `node`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   400 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
