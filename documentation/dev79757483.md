# Text Location Engineering Type

A UUID and offset pair that references some instruction in a Mach-O text
segment.

:::: {#dev79757483us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `text-location`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev79757483ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

A Mach-O file has a single UUID, but there could be several text
segments defined within the file, so the virtual memory layout of the
Mach-O file\'s loadable segments is used as a single number to both
determine which text segment the location references, and identifies the
offset within the text.
:::
