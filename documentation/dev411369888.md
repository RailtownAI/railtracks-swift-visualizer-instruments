# \<annotation-column\> Element

Additional columns that should be displayed as longer-form annotations
of the narrative, like a backtrace or long file path. They will only be
present in the extended detail, not the list view.

:::: {#dev411369888syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<annotation-column>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</annotation-column>`{.CodeLine}
:::
::::

::: {#dev411369888tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
:::
