# \<add-graph\> Element

Add a graph, sliced by the \"slice-type\".

:::: {#dev311951686syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<add-graph>`{.CodeLine}`(title, purpose?, lane{0, 10}, visit-on-selection?, selection-id?)`{.CodeLine}`</add-graph>`{.CodeLine}
:::
