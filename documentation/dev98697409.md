# Disk I/O Operation Engineering Type

A categorical description about the type of operation a disk I/O request
is fulfilling, such as \"Metadata Read\" or \"Page Out\".

:::: {#dev98697409us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `diskio-operation`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          I/O
  Display Width   70 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::
