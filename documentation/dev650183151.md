# \<message\> Element

Defines a pattern to match for the message portion of the event.

:::: {#dev650183151syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<message>`{.CodeLine}`((\s$\?([a-z]+[A-Za-z0-9\-]*[A-Za-z0-9]+)?)?|\?[a-z]+[A-Za-z0-9\-]*[A-Za-z0-9]+(\s*&\s*([^:]+|:\s*\([^\)]+\)))?|("([^"\\]|\\.)*")|\s+)+`{.CodeLine}`</message>`{.CodeLine}
:::
::::
