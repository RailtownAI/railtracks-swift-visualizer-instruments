# Dispatch Work State Engineering Type

The state of a dispatch work item, like a block or a callback/context
pair.

:::: {#dev147390725us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `dispatch-work-state`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          CPU
  Display Width   120 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  state           Value identifies a state and receives a special graph treatment.
:::
::::
