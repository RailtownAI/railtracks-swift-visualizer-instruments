# Byte Array Engineering Type

An eight byte array, packed into a uint64 and stored in network byte
order.

:::: {#dev98042049us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `eight-byte-array`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   120 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev98042049dc .Subhead}
## Display Conventions {#display-conventions .Name}

The value will be stored in network byte order, so it will be first
converted to host byte order then converted to a hex string.
:::

::: {#dev98042049ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded in network byte order
:::
