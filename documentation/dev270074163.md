# \<ktrace-point-schema\> Element

Defines a point schema that is populated with data from the ktrace
mechanism.

:::: {#dev270074163syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<ktrace-point-schema>`{.CodeLine}`(id, title, owner?, purpose?, note?)(attribute*, event-pattern, timestamp-column?, primary-column?, column*)`{.CodeLine}`</ktrace-point-schema>`{.CodeLine}
:::
