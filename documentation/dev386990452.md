# \<create-table\> Element

Tells the instrument, when it\'s added to a trace document, to create a
named data table.

:::: {#dev386990452syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<create-table>`{.CodeLine}`(id, schema-ref, attribute*)`{.CodeLine}`</create-table>`{.CodeLine}
:::
::::

:::: {#dev386990452el .Subhead}
## Elements {#elements .Name}

::: table-wrapper
+-------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Element                                                           | Description                                                                   |
+===================================================================+===============================================================================+
| [id](dev467075485.html#dev467075485){.xRef .AppleTopic}           | A unique name within the scope of this instrument that identifies the table.  |
+-------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [schema-ref](dev310051141.html#dev310051141){.xRef .AppleTopic}   | The schema name that defines the columns of this table.                       |
+-------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [attribute](dev295698768.html#dev295698768){.xRef .AppleTopic}    | A key/value pair that constrains or selects the content of the table.         |
+-------------------------------------------------------------------+-------------------------------------------------------------------------------+
:::
::::
