# Packed ID Engineering Type

A generic, numeric, identifier in the range between 0 and \~4 million
where most of the values occupy the lower range with few unused gaps.

:::: {#dev81199252us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `packed-identifier`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Bit Width       22 bits
  Sentinel        max
:::
::::

::: {#dev81199252ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This identifier is used mainly for 22 bit sequence numbers or serial
numbers. It\'s compact enough to use as a primary column in the Analysis
Core as long as the number of these identifiers is bellow the 22 bit
max - 1. The 22 bit max is reserved as the sentinel.
:::
