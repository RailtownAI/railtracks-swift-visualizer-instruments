## Display Conventions {#display-conventions .Name}

During display, it may be possible to display the process name along
with the pid as long as it\'s not ambiguous.
:::

::: {#dev18612300ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

The process object contains both the pid and the session id so that
processes can be unique between target device recording sessions.
Encoded as an array, the first slot holding a pid and the second slot
holding an iid for the session.
:::
