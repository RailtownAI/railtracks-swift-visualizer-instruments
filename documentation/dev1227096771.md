# \<binds-parameter\> Element

Declares that the attribute must have the same value as given parameter.

:::: {#dev1227096771syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<binds-parameter>`{.CodeLine}`\?[a-z]+[A-Za-z0-9]*(-[A-Za-z0-9]+)*`{.CodeLine}`</binds-parameter>`{.CodeLine}
:::
::::

::: {#dev1227096771tn .Subhead}
## Type Notes {#type-notes .Name}

A parameter name, starting with a ? to indicate that it\'s not a
constant.
