# \<parameter-ref\> Element

The name of a parameter whose current value should constrain what\'s
being displayed.

:::: {#dev641729015syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<parameter-ref>`{.CodeLine}`\?[a-z]+[A-Za-z0-9]*(-[A-Za-z0-9]+)*`{.CodeLine}`</parameter-ref>`{.CodeLine}
:::
::::

::: {#dev641729015tn .Subhead}
## Type Notes {#type-notes .Name}

A parameter name, starting with a ? to indicate that it\'s not a
constant.
:::
