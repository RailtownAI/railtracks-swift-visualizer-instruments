# File Descriptor Engineering Type

UNIX file descriptor.

:::: {#dev393222us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `fd`
  CLIPS Type      `INTEGER`
  Family          I/O
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Signed          true
  Sentinel        max
:::
::::

::: {#dev393222dc .Subhead}
## Display Conventions {#display-conventions .Name}

Should be displayed as a signed value where -1 is treated as an error
:::

::: {#dev393222ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

-1 is valid, but the implementation type is unsigned. A cast to a signed
value should provide the correct conversion.
:::
