# Application Period Engineering Type

Describes an application state. There may be several concurrently
asserted, such as \"Running Foreground\" and \"Spinning\", hence the
term \"period\" is used since we use \"state\" to represent mutually
exclusive states.

:::: {#dev39190651us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `app-period`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   100 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  state           Value identifies a state and receives a special graph treatment.
:::
