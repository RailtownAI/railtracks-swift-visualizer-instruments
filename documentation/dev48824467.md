# Start Engineering Type

Trace relative start time in nanoseconds of the start of some
interesting event.

:::: {#dev48824467us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- --------------
  Mnemonic        `start-time`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   100 pt
  Bit Width       50 bits
  Sentinel        max
:::
::::

::: {#dev48824467ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

For data compression reasons, these values are limited to what can be
fit into 50-bits.
