# Backtrace Engineering Type

A backtrace through various Mach-O text sections, identified by a list
of Mach-O UUIDs and offsets into that image.

:::: {#dev82706587us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `text-backtrace`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   400 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  structured      Value is opaque and can only be accessed via its indexed fields.
  backtrace       
:::
::::

::: {#dev82706587dc .Subhead}
## Display Conventions {#display-conventions .Name}

Typically shows a compressed format of the last frame and the frame
count leading to that frame. In extended views, the entire symbolicated
backtrace is listed.
:::

::: {#dev82706587ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

The first entry is the location of the program counter, and the
remaining frames are return locations in the code. A return location is
the instruction after the call, or in cases where tail calls have been
eliminated, will be the location the thread will be returning to, even
if it\'s not a call to your function.
:::
