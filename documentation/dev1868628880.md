# \<when-os-version-lower-than\> Element

Disables recording if the OS Version of a target device matching given
platform is lower than the specified version.

:::: {#dev1868628880syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<when-os-version-lower-than>`{.CodeLine}`[1-9]{1,2}(\.[0-9])*(\.[0-9])*`{.CodeLine}`</when-os-version-lower-than>`{.CodeLine}
:::
::::
