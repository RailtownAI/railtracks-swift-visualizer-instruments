# Configuration Key Engineering Type

An identifier string used in a key/value configuration table for
modelers to receive complex configurations. This type is suitable for
storing the \"key\" portion of the pair.

:::: {#dev1769488us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `key`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
