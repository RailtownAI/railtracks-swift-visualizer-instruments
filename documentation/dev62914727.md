# Word String Engineering Type

Generic string value representing a string with usually a single word.
The only difference to \`string\` is that it\'s default column-width is
one quarter of \`string\` by default.

:::: {#dev62914727us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `word-string`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   50 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev62914727dc .Subhead}
## Display Conventions {#display-conventions .Name}

This string could be anything. It has a very narrow default column width
only fitting short words like \`get\` or \`action\`. If you need to
encode longer strings, take a look at \`string\` or
\`medium-length-string\`.
:::

::: {#dev62914727ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This should only be used for prototyping purposes when the other
engineering types aren\'t a good match for your implementation.
:::
