# Metadata Engineering Type

A general purpose metadata object that uses a typed array for encoding.

:::: {#dev16973888us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `metadata`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   500 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::
