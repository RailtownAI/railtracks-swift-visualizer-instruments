# \<identifier-field\> Element

The field on the node object from which the identifier will be
determined. For unstructured types like \'node\', this should be an
integer index. For structured types like \'process\', this could be
either an integer index or an element mnemonic. The identifier is used
to disambiguate objects with the same label.

:::: {#dev1639514876syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<identifier-field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</identifier-field>`{.CodeLine}
:::
::::

::: {#dev1639514876tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
