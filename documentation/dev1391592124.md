# \<image-field\> Element

The field on the node object from which the shape will be determined.
For unstructured types like \'node\', this should be an integer index.
For structured types like \'process\', this could be either an integer
index or an element mnemonic.

:::: {#dev1391592124syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<image-field>`{.CodeLine}`([0-9]+)|([a-z]+[a-zA-Z0-9]*)`{.CodeLine}`</image-field>`{.CodeLine}
:::
::::

::: {#dev1391592124tn .Subhead}
## Type Notes {#type-notes .Name}

An identifier of a field in a CLIPS object. Either an integer,
camel-cased string, or snake-case cased string.
