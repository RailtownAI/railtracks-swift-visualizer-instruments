# os_log Metadata (Format String and Args) Engineering Type

A narrative style string that makes up an os_log metadata string (i.e. a
format string and its arguments).

:::: {#dev104923322us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `os-log-metadata`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   500 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  narrative       Value is a typed array, but displayed on a single line as a string.
:::
::::

::: {#dev104923322dc .Subhead}
