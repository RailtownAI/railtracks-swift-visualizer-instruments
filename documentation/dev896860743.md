# \<slice-by-hierarchy\> Element

Describes how to slice the source data to fit into each engineering type
track

:::: {#dev896860743syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<slice-by-hierarchy>`{.CodeLine}`((ignore-slice-column | slice-by-column){1, 4})`{.CodeLine}`</slice-by-hierarchy>`{.CodeLine}
:::
::::

For every slice-type defined in parent augmentation, description of
visual element needs to reference data column mnemonic that exists in
table-ref\'s schema. Each column type needs to be equal to corresponding
slice-type referenced. If filtering by the column is irrelevant for
given slice-type, developer should specify ignore-slice-column element.
