# \<required-input\> Element

Declares that in order to instantiate the modeler for this output, it
must have a table of this specification bound as input.

:::: {#dev575996421syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<required-input>`{.CodeLine}`(schema-ref, attribute*, when?)`{.CodeLine}`</required-input>`{.CodeLine}
:::
::::
