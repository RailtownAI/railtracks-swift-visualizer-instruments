# GPU Frame Number Engineering Type

The GPU frame number. This is expected to just be a trace/application
relative number to track different frames in the UI. This number
doesn\'t actually exist in the driver/HW.

:::: {#dev110362820us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `gpu-frame-number`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Signed          false
  Sentinel        max
:::
::::

::: {#dev110362820dc .Subhead}
## Display Conventions {#display-conventions .Name}

Should be displayed as a unsigned decimal; UINT32_MAX is treated as the
sentinel
:::
