# Thread Name Engineering Type

A name-to-thread mapping.

:::: {#dev42074223us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `thread-name`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   200 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev42074223dc .Subhead}
## Display Conventions {#display-conventions .Name}

For display purposes, the name string and TID as generally presented.
:::

::: {#dev42074223ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as a uint64 where the MSBs are the iid of the string, and the
LSBs are the iid of the thread
:::
