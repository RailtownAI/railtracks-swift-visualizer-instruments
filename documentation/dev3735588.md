# CPU Index Engineering Type

A logical CPU index. This number is typically assigned by the kernel at
boot time.

:::: {#dev3735588us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `core`
  CLIPS Type      `INTEGER`
  Family          CPU
  Display Width   55 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
  Bit Width       16 bits
  Sentinel        max
:::
::::

::: {#dev3735588dc .Subhead}
## Display Conventions {#display-conventions .Name}

Typically displayed like \"CPU 0\"
:::
