# Displayed Surface I/O Surface Size Engineering Type

32-bit unsigned value that represents the width or height of an
IOSurface.

:::: {#dev440140203us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- -------------------------------------
  Mnemonic        `displayed-surface-io-surface-size`
  CLIPS Type      `INTEGER`
  Family          Graphics
  Display Width   80 pt
:::
::::

::: {#dev440140203dc .Subhead}
## Display Conventions {#display-conventions .Name}

Should be displayed as a hex value where -1 is treated as the
non-surface sentinel
:::
