# \<function\> Element

The value or a variable name to constrain the kdebug event\'s function
to.

:::: {#dev196215065syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<function>`{.CodeLine}`(\?[a-z]+[A-Za-z0-9]*(-[A-Za-z0-9]+)*(&.*)?)|(((0x[0-9A-Fa-f]+)|([0-9]+))(\|((0x[0-9A-Fa-f]+)|([0-9]+)))*)`{.CodeLine}`</function>`{.CodeLine}
:::
::::
