# Narrative Significance Engineering Type

A narrative entry significance is an enumerated value that describes how
important a related narrative entry is.

:::: {#dev184352997us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `narrative-significance`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   90 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  Bit Width       3 bits
  Sentinel        max
:::
::::

:::: {#dev184352997dc .Subhead}
## Display Conventions {#display-conventions .Name}

Narrative significance can be given any number of visual treatments, but
typically are not displayed as column values. They may be filterable and
treated with different colors, or simply collapsed if there is a run of
low significant narratives.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev184352997ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

They range from \"pedantic\", which means that the narrative entry is
probably just repeating something that\'s already known, to
\"universal\", which is something so significant that everyone would
find it useful to know.
:::
