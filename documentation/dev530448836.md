# \<selection-id\> Element

Specifies selection identifier of the graph. Allows for synchronizing
selection between different graphs present in the document on differing
hierarchy levels.

:::: {#dev530448836syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<selection-id>`{.CodeLine}`[a-zA-Z]+[a-zA-Z0-9\-\.]*[a-zA-Z0-9]+`{.CodeLine}`</selection-id>`{.CodeLine}
:::
::::
