# Raw String Engineering Type

Raw/Untyped string value.

:::: {#dev49414293us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `raw-string`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev49414293ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

A generic string that doesn\'t represent any particular engineering
type. For example, this is used during the input stage for kdebug string
events, which don\'t have any known meaning yet. This type should not be
abused for strings which do have a more specific type known to them,
like a thread-state or console-text.
:::
