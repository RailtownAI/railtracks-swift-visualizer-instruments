# \<disable\> Element

Declares a condition under which this instrument will disallow
recording.

:::: {#dev605553114syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<disable>`{.CodeLine}`(reason?, recovery-suggestion?, (when-missing | (on-platform*, (when-target-is | when-os-version-lower-than | when-recording-mode-is | when-assertion-fails)?)))`{.CodeLine}`</disable>`{.CodeLine}
:::
::::
