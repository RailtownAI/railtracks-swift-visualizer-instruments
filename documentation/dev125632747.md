# Network Protocol Engineering Type

The name of a network protocol, such as TCP or UDP.

:::: {#dev125632747us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `network-protocol`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          I/O
  Display Width   40 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
