# System CPU Percentage Engineering Type

The percentage of the CPUs being used in a system.

:::: {#dev167969024us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ---------------------------------------------------------------
  Mnemonic        `system-cpu-percent`
  CLIPS Type      `FLOAT`
  Family          CPU
  Display Width   60 pt
  context-free    Values have the same meaning regardless of where they appear.
  Sentinel        max
:::
::::

::: {#dev167969024dc .Subhead}
## Display Conventions {#display-conventions .Name}

This can either be formatted from 0-\>100%, or from
0-\>(NUM_CORES\*100)%, depending on the user\'s defaults setting.
:::

::: {#dev167969024ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

The value stored here should be from 0-\>(NUM_CORES\*100)%
:::
