# \<interval-schema\> Element

Defines a table schema that can be used to store intervals (data with a
duration).

:::: {#dev191168761syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<interval-schema>`{.CodeLine}`(id, title, owner?, purpose?, note?)(attribute*, start-column, duration-column, primary-column{0, 2}, column*)`{.CodeLine}`</interval-schema>`{.CodeLine}
:::
::::
