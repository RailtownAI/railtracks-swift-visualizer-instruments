# 128-bit UUID Engineering Type

A universally unique identifier, as specified by ISO/IEC 11578:1996 or
ISO/IEC 9834-8:2005.

:::: {#dev7471155us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `uuid`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev7471155dc .Subhead}
## Display Conventions {#display-conventions .Name}

The UUID will be displayed in string form, such as
123e4567-e89b-12d3-a456-426655440000.
:::

::: {#dev7471155ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded as an array of 2 8-byte arrays, the first being the most
significant bits of the UUID and the second being the least.
:::
