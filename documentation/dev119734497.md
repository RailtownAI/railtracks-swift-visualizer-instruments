# \<instrument\> Element

Defines an instrument that appears in the Instruments library.

:::: {#dev119734497syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<instrument>`{.CodeLine}`(id, version?, title, owner?, category, purpose, (icon), beta?, guide?, import-parameter*, create-parameter*, limitations?, create-table{1, unbounded}, activate-augmentation*, graph{0, 10}, (list | time-slice | calltree | narrative | aggregation | object-graph){1, 20}, engineering-type-track*, defaults?)`{.CodeLine}`</instrument>`{.CodeLine}
:::
::::

+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| Element                                                                       | Description                                                                   |
+===============================================================================+===============================================================================+
| [id](dev170918154.html#dev170918154){.xRef .AppleTopic}                       | A unique id in reverse DNS notation that globally identifies your instrument. |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [version](dev279970147.html#dev279970147){.xRef .AppleTopic}                  | A version number that helps Instruments resolve conflicts. Higher versions    |
|                                                                               | overwrite lower versions.                                                     |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [title](dev233963839.html#dev233963839){.xRef .AppleTopic}                    | Descriptive title that will appear in the Instruments library.                |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [owner](dev234750280.html#dev234750280){.xRef .AppleTopic}                    | Owner specific to this instrument. Assumes the package owner if none given.   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [category](dev289276251.html#dev289276251){.xRef .AppleTopic}                 | Category identifier to help group this instrument in the library.             |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [purpose](dev283836779.html#dev283836779){.xRef .AppleTopic}                  | A longer description of the value that this instrument provides to a trace.   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [icon](dev208470310.html#dev208470310){.xRef .AppleTopic}                     | The icon the instrument should use.                                           |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [beta](dev206831897.html#dev206831897){.xRef .AppleTopic}                     | When true, hides the instrument from the Library. The instrument still        |
|                                                                               | appears in trace and tracetemplate files.                                     |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [guide](dev229638443.html#dev229638443){.xRef .AppleTopic}                    | A note that documentation tools may extract when creating a user\'s guide.    |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [import-parameter](dev527499732.html#dev527499732){.xRef .AppleTopic}         | Declares the name of a parameter that can be used in table definitions.       |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [create-parameter](dev494862765.html#dev494862765){.xRef .AppleTopic}         | Creates a parameter specific to this instrument. Parameters show up in the UI |
|                                                                               | and command line as recording options.                                        |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [limitations](dev370147722.html#dev370147722){.xRef .AppleTopic}              | Describes the environments in which the instrument cannot be used.            |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [create-table](dev386990452.html#dev386990452){.xRef .AppleTopic}             | Tells the instrument, when it\'s added to a trace document, to create a named |
|                                                                               | data table.                                                                   |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [activate-augmentation](dev653459957.html#dev653459957){.xRef .AppleTopic}    | Tells the instrument, when it\'s added to a trace document, to activate an    |
|                                                                               | augmentation.                                                                 |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [graph](dev146604261.html#dev146604261){.xRef .AppleTopic}                    | Defines the graph, or track, that the instrument will present. There can be   |
|                                                                               | several.                                                                      |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [list](dev135397616.html#dev135397616){.xRef .AppleTopic}                     | Creates a table view in the detail area.                                      |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [time-slice](dev247464238.html#dev247464238){.xRef .AppleTopic}               | Creates a table view in the detail area that only displays data that          |
|                                                                               | intersects the inspection head.                                               |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [calltree](dev194314496.html#dev194314496){.xRef .AppleTopic}                 | Creates a call-tree view in the detail area.                                  |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [narrative](dev220332320.html#dev220332320){.xRef .AppleTopic}                | Creates a view in the detail area optimized for the \"narrative\" engineering |
|                                                                               | type.                                                                         |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [aggregation](dev243400988.html#dev243400988){.xRef .AppleTopic}              | Creates an aggregate view (e.g. summary with totals and averages) in the      |
|                                                                               | detail area.                                                                  |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [object-graph](dev274989368.html#dev274989368){.xRef .AppleTopic}             | Creates an object graph view in the detail area.                              |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [engineering-type-track](dev699859477.html#dev699859477){.xRef .AppleTopic}   | Defines engineering type data track data source. When this Instrument is      |
|                                                                               | present in the trace document, this data source is queried and matching       |
|                                                                               | engineering type tracks are created.                                          |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
| [defaults](dev287768917.html#dev287768917){.xRef .AppleTopic}                 | Defines the default values used when the instrument is first added to a trace |
|                                                                               | document.                                                                     |
+-------------------------------------------------------------------------------+-------------------------------------------------------------------------------+
