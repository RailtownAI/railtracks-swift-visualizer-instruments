# Dispatch Queue Engineering Type

A dispatch queue object.

:::: {#dev69730475us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `dispatch-queue`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          CPU
  Display Width   250 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

::: {#dev69730475dc .Subhead}
## Display Conventions {#display-conventions .Name}

The UI should present the first field, which is the name, and the second
field which is the user-space object pointer to help differentiate
queues which have the same name. If the name is the sentinel value, then
just the address is displayed.
:::
