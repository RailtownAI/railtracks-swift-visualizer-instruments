# CFRunLoop Result Engineering Type

Determines why a corresponding cfrunloop run interval ended. Valid
values are 1-4. 0 is treated as \"Unknown\" for compatibility reasons.

:::: {#dev107413726us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `cfrunloop-result`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  Bit Width       3 bits
  Sentinel        max
:::
::::

::: {#dev107413726dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displays the reason a runloop run ended as string, e.g. \"Finished\" or
\"Timed Out\".
:::
