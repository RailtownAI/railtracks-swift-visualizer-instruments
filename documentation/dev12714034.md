# Boolean Engineering Type

A yes/no boolean value. Encoded as 0 and 1. Other values are illegal.

:::: {#dev12714034us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `boolean`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  Bit Width       2 bits
  Sentinel        max
:::
::::

::: {#dev12714034dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displays \"Yes\" or \"No\" or \"n/a\"
:::
