# Narrative Certainty Engineering Type

A narrative entry certainty is a value from 1 to 100 that describes how
certain a related narrative entry is.

:::: {#dev136970465us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `narrative-certainty`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   55 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  Bit Width       7 bits
  Sentinel        max
:::
::::

:::: {#dev136970465dc .Subhead}
## Display Conventions {#display-conventions .Name}

Narrative certainties can be given any number of visual treatments, but
typically are not displayed as column values. They may be rendered as a
different text color or background if they are uncertain, say below 50.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev136970465ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Higher numbers indicate higher certainty, where 100 is absolutely
certain, and 0 is demonstrably questionable.
:::
