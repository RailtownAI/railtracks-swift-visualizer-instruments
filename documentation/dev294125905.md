# \<hidden-column\> Element

Column from the schema that should be displayed in a list column, but is
hidden by default.

:::: {#dev294125905syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<hidden-column>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</hidden-column>`{.CodeLine}
:::
::::

::: {#dev294125905tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
:::
