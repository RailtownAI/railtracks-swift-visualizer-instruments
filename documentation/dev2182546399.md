# \<type-priority\> Element

A priority that specifies what should be the order of the tracks, when
multiple types are available on the same hierarchy level.

:::: {#dev2182546399syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<type-priority>`{.CodeLine}`-?[0-9]+`{.CodeLine}`</type-priority>`{.CodeLine}
:::
::::

::: {#dev2182546399tn .Subhead}
## Type Notes {#type-notes .Name}
