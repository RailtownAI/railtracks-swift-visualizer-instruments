# kdebug Class Engineering Type

A kdebug class field value. This value, along with a kdebug-subclass,
provide a namespace for a kdebug-code.

:::: {#dev40304752us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-class`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   60 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev40304752dc .Subhead}
## Display Conventions {#display-conventions .Name}

Codes for kdebug are usually used for debugging, usually in hex.
