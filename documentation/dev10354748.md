# State Engineering Type

Generic string value representing a state.

:::: {#dev10354748us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `state`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   150 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  state           Value identifies a state and receives a special graph treatment.
:::
::::

::: {#dev10354748dc .Subhead}
## Display Conventions {#display-conventions .Name}

This string could be anything, but state names are generally short and
easy to read quickly.
:::

::: {#dev10354748ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

This should only be used for prototyping purposes when the other
engineering types aren\'t a good match for your implementation.
:::
