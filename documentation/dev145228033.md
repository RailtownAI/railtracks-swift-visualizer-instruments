# Byte Array Engineering Type

An eight byte array, packed into a uint64 and stored in little endian
byte order.

:::: {#dev145228033us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `eight-byte-array-le`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   120 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev145228033dc .Subhead}
## Display Conventions {#display-conventions .Name}

The value will be stored in little endian byte order, so it will first
be converted to network byte order before being displayed in hex.
:::

::: {#dev145228033ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

Encoded in little endian byte order
:::
