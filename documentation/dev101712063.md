# Visual Connection Filter Engineering Type

An identifier that can be used to filter out drawn visual element.

:::: {#dev101712063us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `connection-filter`
  CLIPS Type      `INTEGER`
  Family          General
  Display Width   80 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  identifier      Value is treated as an identifier.
:::
::::

:::: {#dev101712063dc .Subhead}
## Display Conventions {#display-conventions .Name}

The graphing code can accept a 64-bit number to use as a filter. Only
rows matching this filter will be drawn. Setting to \~0x0 means always
draw the row.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::
