# Key Value Array Engineering Type

Typed array of engineering values which are interpreted as a pairs of
key values in the Instruments UI.

:::: {#dev101449922us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `key-value-array`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
:::
::::

::: {#dev101449922dc .Subhead}
## Display Conventions {#display-conventions .Name}

Displayed as a string. In vertical views, double-column appearance is
applied.
:::
