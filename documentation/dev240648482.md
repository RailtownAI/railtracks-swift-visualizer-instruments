# \<name\> Element

The name of the parameter, unique with the implied scope of the
parameter.

:::: {#dev240648482syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<name>`{.CodeLine}`\?[a-z]+[A-Za-z0-9]*`{.CodeLine}`</name>`{.CodeLine}
:::
::::

::: {#dev240648482tn .Subhead}
## Type Notes {#type-notes .Name}

A parameter name, starting with a ? to indicate that it\'s not a
constant, but must not contain \'-\' characters to avoid confusing
expression parsers.
:::

## Syntax Example {#syntax-example .Name}

:::
