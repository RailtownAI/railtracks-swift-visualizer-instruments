# kdebug Signpost Variant Engineering Type

Specifies if the KDebug signpost is a \"Start\", \"End\", or \"Point\"
(also known as NONE) event.

:::: {#dev207159584us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kdebug-signpost-variant`
  CLIPS Type      `STRING` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   70 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  event           Value identifies an event and receives a special graph treatment.
:::
::::
