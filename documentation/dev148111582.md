# \<point-schema\> Element

Defines a table schema that can be used to store points (no duration).

:::: {#dev148111582syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<point-schema>`{.CodeLine}`(id, title, owner?, purpose?, note?)(attribute*, timestamp-column, primary-column?, column*)`{.CodeLine}`</point-schema>`{.CodeLine}
:::
