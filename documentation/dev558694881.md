# \<containment-level-from\> Element

Allows a single visual object to be built up from several rows, where
each row represents a different level of containment (like an onion).

:::: {#dev558694881syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<containment-level-from>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</containment-level-from>`{.CodeLine}
:::
::::

::: {#dev558694881tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
