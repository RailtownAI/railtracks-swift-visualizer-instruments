# kperf Backtrace Engineering Type

A raw backtrace from kperf.

:::: {#dev22544469us .Subhead}
## Usage {#usage .Name}

::: table-wrapper
  Attribute       Value
  --------------- ------------------------------------------------------------------------------
  Mnemonic        `kperf-bt`
  CLIPS Type      `EXTERNAL-ADDRESS` or the `SYMBOL` \'`sentinel`\'
  Family          General
  Display Width   300 pt
  categorical     Value cannot be summed or averaged. They have no inherent height in a graph.
  structured      Value is opaque and can only be accessed via its indexed fields.
:::
::::

:::: {#dev22544469dc .Subhead}
## Display Conventions {#display-conventions .Name}

Debugging display only. Converting these won\'t be trivial so it\'s not
something a display formatter should be trying to do on the fly.

::: Alert
*Note:* This engineering type is usually only displayed for debugging.
It\'s not intended to be displayed in an instrument or augmentation.
:::
::::

::: {#dev22544469ec .Subhead}
## Encoding Notes {#encoding-notes .Name}

These backtraces come from the kernel and require processing before they
can be used as normal backtraces. This object contains all the pieces
needed for reconstruction. Encoded as an array where the first slot is
the backtrace, the second is the PC value, the 3rd is the process\'s iid
and values after that are register values used in fix up.
:::
