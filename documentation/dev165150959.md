# \<import-schema\> Element

Allows schemata from other distributions to be referenced and used by
modelers and instruments.

:::: {#dev165150959syn .Subhead}
## Syntax {#syntax .Name}

::: CodeLines
`<import-schema>`{.CodeLine}`[a-z]+[a-z0-9\-]*[a-z0-9]*(\-UUID)?`{.CodeLine}`</import-schema>`{.CodeLine}
:::
::::

::: {#dev165150959tn .Subhead}
## Type Notes {#type-notes .Name}

A short identifier string that is lower case and contains no whitespace.
